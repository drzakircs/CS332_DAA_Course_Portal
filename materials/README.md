# Learning Materials Folder

Upload weekly HTML learning material here.

Examples:

```text
CS332_Week01_Introduction.html
CS332_Week02_Lecture.html
CS332_Week02_Practice.html
CS332_Week03_InteractiveMaterial.html
```

The portal automatically detects the week number and lists every matching `.html` / `.htm` file under that week's **Learning Material** section.

Supported markers:

```text
Week1
Week01
Week_1
Week_01
Week-1
Week-01
week 1
week 01
```

Do not edit `index.html`, `app.js`, or `course.json` merely to add/remove weekly material.
