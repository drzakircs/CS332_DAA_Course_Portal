Your mental toolkit

🧩 Six ideas to connect before the midterm

1 · Algorithm correctness

Precondition → invariant/induction → postcondition. A correct algorithm produces the promised result.

2 · Asymptotic bounds

O is an upper bound; Ω is a lower bound; Θ is a tight bound. Specify what input case you mean.

3 · Iterative analysis

Count basic operations. Nested loops often use sums such as 1+2+···+(n−1).

4 · Recursive analysis

Write the recurrence, specify the base case, and compute work per recursion level.

5 · Divide-and-conquer

Divide the problem, solve smaller problems recursively, then combine the answers.

6 · Sorting families

Bubble/Selection/Insertion use comparisons; Counting/Bucket/Radix require extra assumptions about keys.
