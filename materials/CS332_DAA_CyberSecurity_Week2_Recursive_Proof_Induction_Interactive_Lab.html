Why does recursion work?

A recursive algorithm solves size n by using a smaller instance. Mathematical induction gives the matching proof technique.

Core idea

Recursion has three essential ingredients

1. Same problem

The function calls itself to solve the same kind of problem.

2. Smaller input

Each recursive call must make measurable progress toward a simpler input.

3. Base case

The smallest valid input is solved directly without another recursive call.

Important: recursion is not “a function calling itself.” Correct recursion must eventually reach a base case.

Running example

Recursive SUM(A,n)

SUM(A, n) if n == 0: return 0 else: return SUM(A, n−1) + A[n−1]

Specification

SUM(A,n) returns the sum of the first n elements of A.

Base: n=0 → return 0.

Recursive: sum first n−1 elements, then add A[n−1].

The proof connection

Recursion and induction have the same structure

Recursive algorithmTo solve size n, solve a smaller instance.
→
Induction hypothesisAssume that smaller recursive result is correct.
→
Inductive stepUse that smaller correct answer to prove the size-n answer.

Memory sentence: recursion reduces the problem; induction justifies trusting the smaller result.

Proof template

How to prove a recursive algorithm

1. Claim

State exactly what the function returns for every valid input size.

2. Base Case

Prove the smallest input is handled correctly.

3. Hypothesis

Assume the recursive call is correct on a smaller input.

4. Step

Use the smaller correct answer to prove the current answer.

Then check termination: show that every recursive call moves toward a base case.

Worked proof

Correctness proof for SUM(A,n)

Claim

For every n≥0, SUM(A,n) returns A[0]+A[1]+…+A[n−1].

Base case: n=0

The algorithm returns 0. The sum of zero elements is 0. So the claim holds.

Induction hypothesis

Assume SUM(A,n−1) correctly returns A[0]+…+A[n−2].

Inductive step

The algorithm returns SUM(A,n−1)+A[n−1]. By the hypothesis, that equals the sum of the first n elements.

Conclusion: by induction, SUM(A,n) is correct for all n≥0.

Total correctness

Correct answer is not enough — recursion must terminate

For SUM(A,n)

  • n is non-negative.
  • Every call changes n to n−1.
  • n strictly decreases.
  • Eventually n reaches 0.

Decreasing measure

n → n−1 → … → 0

A recursive function can have a sensible formula but still fail if its recursive argument does not move toward a base case.

Student challenge

Write a proof for recursive MAX

RMAX(A,n) if n == 1: return A[0] else: return max(RMAX(A,n−1), A[n−1])

Explain: claim, base case, induction hypothesis, inductive step, termination.

Model: Claim: returns the maximum of the first n elements. Base n=1: returns A[0], the maximum of one element. Hypothesis: assume RMAX(A,n−1) returns the maximum of the first n−1 elements. Step: max(that result, A[n−1]) is therefore the maximum of the first n elements. Termination: n decreases by 1 until n=1.
Common mistakes

What should students avoid?

Assuming the current case

The hypothesis must concern a smaller input, not n itself.

Skipping the base case

Without a base case, the induction chain has no foundation.

Ignoring termination

Correctness of the returned formula does not automatically prove recursive calls terminate.

Vague claim

“It works” is not a proof claim. State exactly what the function returns.

Wrong smaller problem

The recursive call must match what the induction hypothesis covers.

Good workflow

Claim → Base → Hypothesis → Step → Termination.
