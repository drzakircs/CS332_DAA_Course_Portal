Course Description

This course provides comprehensive knowledge of algorithms and develops understanding of the principles and techniques used in their design and analysis. It covers the role of algorithms in computing, analysis of input and input size, asymptotic notation, sorting algorithm analysis, loop invariants, recursion and recurrence relations, major algorithm-design techniques, heaps and search trees, graph algorithms, shortest-path methods, string matching, data compression, and an introduction to computational complexity classes.

Prerequisites

  • CS-214 Data Structures and Algorithms
  • CS-214L Data Structures and Algorithms Lab

The course guide does not prescribe a specific programming language or software tool for this theory course; it explicitly uses pseudocode/flowcharts as algorithm representations.
